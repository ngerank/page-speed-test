# Page Speed Test - Ngerank

A lightweight and simple tool to measure page load speed based on iframe load time.

## Features
- Enter a URL to test
- See real iframe load progress
- Measure page load time in seconds
- Auto-generate a speed score based on load time:
  - Excellent (≤ 2s)
  - Good (≤ 4s)
  - Average (≤ 7s)
  - Poor (> 7s)
- Fast, simple, dark mode design
- No dependencies

## Tech Stack
- HTML5
- CSS3
- JavaScript (Vanilla)

## Usage
1. Enter the URL you want to test.
2. Click "Test Page Speed".
3. See real load progress and load time with score.
